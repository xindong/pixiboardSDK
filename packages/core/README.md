# @pixi-board/core

Planned headless document/store package for PixiBoardJS.

This directory is intentionally a documentation-only boundary marker in the
planning phase. It must remain independent of DOM, PixiJS, Tauri, plugins and
the product UI. Implementation starts at the P1 milestone described in
[`docs/09-delivery-roadmap.md`](../../docs/09-delivery-roadmap.md).
