关于这个 Demo

这个画布由真实的 pixiboardjs 包 + @pixi-board/renderer-pixi 渲染器驱动， 不是截图或视频。你现在看到的每一次拖拽、缩放和撤销，都是在调用 SDK 的公共 API。

核心特性

  • 扁平数据模型 — 文档是纯 JSON，节点没有父子嵌套，渲染对象随时可销毁重建。
  • Node Type Registry — 内置矩形、文本、图片、视频等类型与自定义类型统一注册，见「任务卡」示例。
  • Transaction / History — 所有写入都进入同一条 transaction 管线，撤销重做开箱即用。
  • Viewport 控制 — pan / zoom / fitBounds 是 SDK 的一等能力，非画布库私有实现。
  • Web + Tauri — 同一套 core 与 capabilities 可以在浏览器与 Tauri WebView 中运行。

代码片段

import { createPixiBoard } from "pixiboardjs";
import { PixiBoardRenderer } from "@pixi-board/renderer-pixi";

const board = await createPixiBoard({
  container: document.querySelector("#board"),
  rendererFactory: (o) => new PixiBoardRenderer(o),
});
await board.ready;

await board.nodes.create({
  type: "rect",
  x: 40, y: 40, width: 120, height: 80,
  props: { fill: 0x7c8cf8 },
});
