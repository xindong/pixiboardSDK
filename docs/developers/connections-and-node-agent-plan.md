# 连线与节点 Agent：架构决策摘要

公开 API 和示例见 [使用指南](connections-and-node-agent-local.md)。

- 关系仅保存在扁平文档 metadata.connections；不使用节点 props.from/to 或另一个关系数据库。
- Core metadata 补丁属于文档事务，参与撤销/重做；节点删除在同一事务清理相关关系。
- SDK 浏览器控制器负责连线几何、索引、命中、手势和复制粘贴；Pixi 负责绘制，不使用 DOM SVG 模拟整张图。
- 样式和启用状态可由宿主全局设置持有，不必写入文档历史。
- 节点 Agent 是无服务端绑定的控制器：采集上下文、资源解析、提示词和提交通过回调组合。图遍历有去重和预算；异步结果在画布改变或取消后失效。
- 处理任务使用宿主自定义节点；结果就绪后显式 nodes.convert，保留 ID 与几何。SDK 不管理 AI 任务。
- 消费方只使用 npm 包公开入口；私有 workspace 实现不作为运行时依赖。

本阶段不支持自动避障、多端口定义或自动执行 AI 任务。性能承诺以实测为准，不从索引结构推断帧率。
